# Ultraproducts

**Definition.** Let $I$ be a set, $\mathcal P (I)$ be the powerset of $I$. A **filter** $\mathcal F$ (on $I$) is a non-empty subset of $\mathcal P(I)$ satisfying the following:

1. $\emptyset \notin \mathcal F$
2. $A, B \in \mathcal F \implies A \cap B \in \mathcal F$ (Closed under finite intersections)
3. $A \in \mathcal F, A \subseteq B \implies B \in \mathcal F$ (Upward closed) 

**Example.**

Let $I$ be an infinite set.

+ Check that $D_i = \{X \subseteq I \mid i \in X\}$ is a filter for any $i \in I$. We call it the **principal filter** generated by $i$.
+ Check that $\mathcal F_{cof} = \{X \subseteq I \mid I \setminus X \text{ is finite} \}$ is a filter. We call it the **cofinite filter** (or Fréchet filter) on $I$.

**Definition.** Let $I$ be a set and $\mathcal F$ be a filter on $I$. We say that $\mathcal F$ is an **ultrafilter** if for any $X \subseteq I$, either $X \in \mathcal F \text{ or } I \setminus X \in \mathcal F$.

**Remark.** If $I$ is finite, any ultrafilter on $I$ is a principal filter. In fact, if $\mathcal F$ is an ultrafilter on $I$ and there exists a finite set $A \in \mathcal F$, then $\mathcal F$ is a principal filter.

**Proof.** Let $A = \{a_1, a_2, \dots, a_n\} \in \mathcal F$. We claim that for some $k$, $\{a_k\} \in \mathcal F$. 
Suppose towards a contradiction that for all $1 \le k \le n$, $\{a_k\} \notin \mathcal F$. Since $\mathcal F$ is an ultrafilter, their complements $I \setminus \{a_k\} \in \mathcal F$. Since filters are closed under finite intersections, $\bigcap_{k=1}^n (I \setminus \{a_k\}) \in \mathcal F$. 
By De Morgan's laws, this intersection is exactly $I \setminus A$. Thus $I \setminus A \in \mathcal F$. But we assumed $A \in \mathcal F$, which implies $A \cap (I \setminus A) = \emptyset \in \mathcal F$, contradicting the definition of a filter. 
Therefore, there exists some $a_k \in A$ such that $\{a_k\} \in \mathcal F$, which means $\mathcal F$ is the principal filter generated by $a_k$.

**Lemma (Extension of filters).** Let $I$ be an index set and $\mathcal F$ be a filter on $I$. If there exists $A \subseteq I$ such that $A \notin \mathcal F$ and $I \setminus A \notin \mathcal F$, then there is a filter $\mathcal F'$ such that $A \in \mathcal F'$ and $\mathcal F \subseteq \mathcal F'$.

**Proof.** Define $\mathcal F' = \{ X \subseteq I \mid \exists Y \in \mathcal F \text{ such that } Y \cap A \subseteq X \}$. 
Since $I \setminus A \notin \mathcal F$, for any $Y \in \mathcal F$, $Y \not\subseteq I \setminus A$, which implies $Y \cap A \neq \emptyset$. Thus $\emptyset \notin \mathcal F'$. It is routine to check that $\mathcal F'$ is upward closed and closed under finite intersections. Clearly, $\mathcal F \subseteq \mathcal F'$ (take $Y = X$) and $A \in \mathcal F'$ (take $Y = I$). 

**Theorem (Existence of ultrafilters).** Let $I$ be a set and $\mathcal F$ be a filter on $I$. There is an ultrafilter $\mathcal U$ extending $\mathcal F$ (i.e., $\mathcal F \subseteq \mathcal U$).

**Proof.** We use Zorn's lemma. Let $\mathbb{P} = \{ \mathcal{G} \mid \mathcal{G} \text{ is a proper filter on } I \text{ and } \mathcal F \subseteq \mathcal{G} \}$, partially ordered by inclusion $\subseteq$.
$\mathbb{P}$ is non-empty since $\mathcal F \in \mathbb{P}$. For any chain $\mathcal{C}$ in $\mathbb{P}$, let $\mathcal{H} = \bigcup_{\mathcal{G} \in \mathcal{C}} \mathcal{G}$. It's easy to verify that $\mathcal{H}$ is a proper filter extending $\mathcal F$, hence $\mathcal{H} \in \mathbb{P}$ is an upper bound for $\mathcal{C}$.
By Zorn's lemma, $\mathbb{P}$ has a maximal element $\mathcal U$.
To see $\mathcal U$ is an ultrafilter, suppose there is $A \subseteq I$ such that $A \notin \mathcal U$ and $I \setminus A \notin \mathcal U$. By the Extension Lemma, there is a proper filter $\mathcal U'$ strictly containing $\mathcal U$, contradicting the maximality of $\mathcal U$. Thus $\mathcal U$ is an ultrafilter. 

**Definition.** Let $I$ be a set. A **non-principal ultrafilter** $\mathcal U$ on $I$ is an ultrafilter on $I$ that is not principal.

**Corollary.** Let $I$ be an infinite set. There is a non-principal ultrafilter on $I$.

**Proof.** Consider the cofinite filter $\mathcal F_{cof}$. By the Existence Theorem, there exists an ultrafilter $\mathcal U$ extending $\mathcal F_{cof}$. For any finite set $X \subseteq I$, its complement $I \setminus X \in \mathcal F_{cof} \subseteq \mathcal U$. Because $\mathcal U$ is a proper filter, $X \notin \mathcal U$. Thus $\mathcal U$ does not contain any singletons, so it cannot be a principal filter. 

**Definition.** Let $I$ be an index set, $\mathscr L$ be a first-order language. For each $i \in I$, let $\bar{M}_i$ be an $\mathscr L$-structure. Let $\mathcal U$ be an ultrafilter on $I$. 
The set

$$
\prod_{i\in I} \bar{M}_i \Big/ \mathcal U
$$

is called the **ultraproduct** of $\bar{M}_i$.

As a set, note that $\mathcal U$ defines an equivalence relation $\sim_{\mathcal U}$ on the Cartesian product $\prod _{i \in I} M_i$:
For $a = (a_i)_{i\in I}, b = (b_i)_{i \in I} \in \prod_{i\in I} M_i$, we say $a \sim_{\mathcal U} b$ if $\{i \in I \mid a_i = b_i\} \in \mathcal U$. We denote the equivalence class of $a$ by $[a]$.

Now we define the $\mathscr L$-structure on the ultraproduct $\prod _{i\in I} M_i / \mathcal U$:

+ **Constant symbols:** For any constant $c \in \mathscr L$, 
  
  $$
  c^{\prod \bar{M}_i / \mathcal U} := [(c^{\bar{M}_i})_{i \in I}]
  $$

+ **Function symbols:** For any $n$-ary function $f \in \mathscr L$ and elements $[a^1], \dots, [a^n]$ in the ultraproduct,
  
  $$
  f^{\prod \bar{M}_i / \mathcal U}([a^1], \cdots, [a^n]) := [(f^{\bar{M}_i}(a^1_i, \cdots, a^n_i))_{i \in I}]

  $$

+ **Relation symbols:** For any $n$-ary relation $R \in \mathscr L$,
  
  $$
  \prod_{i\in I} \bar{M}_i \Big/ \mathcal U \models R([a^1], \cdots, [a^n]) \iff \{i \in I \mid \bar{M}_i \models R(a^1_i, \cdots, a^n_i)\} \in \mathcal U
  $$

**Example.** Let $\mathcal U$ be a principal filter on a set $I$, i.e., $\mathcal U = D_k$ for some fixed $k \in I$. Let $\bar{M}_i$ be $\mathscr L$-structures. Then the ultraproduct is isomorphic to the $k$-th structure:

$$
\prod_{i \in I} \bar{M}_i \Big/ \mathcal U \cong \bar{M}_k
$$

**Theorem (Łoś's Theorem).** Let $I$ be an index set, and $\varphi(x_1, \cdots,x_n)$ be an $\mathscr L$-formula. Let $\mathcal U$ be an ultrafilter on $I$, and $\{\bar{M}_i\}_{i \in I}$ be a family of $\mathscr L$-structures. For any elements $f_1, \cdots, f_n \in \prod_{i\in I} M_i / \mathcal U$, where $f_k := [(f_k(i))_{i\in I}]$, we have:

$$
\prod_{i\in I}\bar{M}_i \Big/ \mathcal U \models \varphi[f_1, \cdots, f_n] \iff \{i \in I \mid \bar{M}_i \models \varphi[f_1(i), \cdots, f_n(i)] \} \in \mathcal U
$$

**Proof.** We proceed by induction on the complexity of the formula $\varphi$. For simplicity, let $[f_i]$ denote the equivalence class $f_i/\sim_{\mathcal{U}}$.

*Atomic case:* If $\varphi$ is an atomic formula of the form $R(x_1, \dots, x_n)$ or $t_1 = t_2$, the theorem holds directly by the definition of the interpretations of relation symbols and function symbols in the ultraproduct.

*Inductive step:*

*Case 1: Conjunction,* $\varphi := (\theta \land \psi)$.

$$
\begin{aligned}

& \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \models \varphi[[f_1], \dots, [f_n]] \\

\iff & \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \models \theta[[f_1], \dots, [f_n]] \text{ and } \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \models \psi[[f_1], \dots, [f_n]] \\

\stackrel{\text{IH}}{\iff} & \underbrace{\{i \in I \mid \mathcal{M}_i \models \theta[f_1(i), \dots, f_n(i)]\}}_{=: A} \in \mathcal{U} \text{ and } \underbrace{\{i \in I \mid \mathcal{M}_i \models \psi[f_1(i), \dots, f_n(i)]\}}_{=: B} \in \mathcal{U} \\

\iff & A \cap B \in \mathcal{U} \quad \text{(since } \mathcal{U} \text{ is a filter and closed under finite intersection)} \\

\iff & \{i \in I \mid \mathcal{M}_i \models (\theta \land \psi)[f_1(i), \dots, f_n(i)]\} \in \mathcal{U}.

\end{aligned}

$$

*Case 2: Negation,* $\varphi := \neg \theta$.

$$
\begin{aligned}

& \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \models \varphi[[f_1], \dots, [f_n]] \\

\iff & \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \not\models \theta[[f_1], \dots, [f_n]] \\

\stackrel{\text{IH}}{\iff} & \{i \in I \mid \mathcal{M}_i \models \theta[f_1(i), \dots, f_n(i)]\} \notin \mathcal{U} \\

\iff & \{i \in I \mid \mathcal{M}_i \models \neg\theta[f_1(i), \dots, f_n(i)]\} \in \mathcal{U} \quad \text{(since } \mathcal{U} \text{ is an ultrafilter)}.

\end{aligned}

$$

*Case 3: Existential quantifier,* $\varphi := \exists x \theta(x, x_1, \dots, x_n)$.

$$
\begin{aligned}

& \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \models \varphi[[f_1], \dots, [f_n]] \\

\iff & \text{there is } g \in \prod_{i\in I} M_i \text{ such that } \prod_{i\in I} \mathcal{M}_i/\mathcal{U} \models \theta[[g], [f_1], \dots, [f_n]] \\

\stackrel{\text{IH}}{\iff} & \{i \in I \mid \mathcal{M}_i \models \theta[g(i), f_1(i), \dots, f_n(i)]\} \in \mathcal{U} \\

\iff & \{i \in I \mid \mathcal{M}_i \models \exists x \theta(x, f_1(i), \dots, f_n(i))\} \in \mathcal{U}.

\end{aligned}

$$

**Theorem (Compactness via Ultraproducts).** Let $\Sigma$ be a set of $\mathscr{L}$-sentences. If for any finite subset $\Sigma_0 \subseteq_{fin} \Sigma$, there is a model $\mathcal{M}_{\Sigma_0} \models \Sigma_0$ (i.e., $\Sigma$ is finitely satisfiable), then $\Sigma$ has a model (i.e., there is $\mathcal{M} \models \Sigma$).

**Proof.** It suffices to consider the case where $\Sigma$ is infinite (otherwise it is trivially true).

Let the index set $I$ be the collection of all finite subsets of $\Sigma$:

$$
I = \{\Sigma_0 \mid \Sigma_0 \text{ is finite and } \Sigma_0 \subseteq \Sigma\}.
$$

By assumption, for any index $i \in I$ (which is a finite set of sentences), there is a structure $\mathcal{M}_i$ such that $\mathcal{M}_i \models \phi$ for every $\phi \in i$.

For any $\mathscr{L}$-sentence $\theta \in \Sigma$, we define the set of indices containing $\theta$:

$$
X_\theta := \{i \in I \mid \theta \in i\}.
$$

Consider the family of such sets:

$$
E = \{X_\theta \mid \theta \text{ is an } \mathscr{L}\text{-sentence, and } \theta \in \Sigma\}.
$$

The family $E$ generates a filter because it has the finite intersection property. Indeed, for any finite collection $\theta_1, \dots, \theta_n \in \Sigma$, the finite set $i^* = \{\theta_1, \dots, \theta_n\} \in I$ is an index that belongs to $X_{\theta_1} \cap \dots \cap X_{\theta_n}$.

By the Extension Lemma and the Existence of Ultrafilters, we can take an ultrafilter $\mathcal{U}$ extending $E$ (so $E \subseteq \mathcal{U}$).

*Claim:* The ultraproduct $\prod_{i \in I} \mathcal{M}_i / \mathcal{U} \models \Sigma$.

Let $\theta \in \Sigma$. Then $X_\theta \in E \subseteq \mathcal{U}$. By definition, for every index $i \in X_\theta$, we have $\theta \in i$, which implies $\mathcal{M}_i \models \theta$. Therefore, $\{i \in I \mid \mathcal{M}_i \models \theta\} \supseteq X_\theta \in \mathcal{U}$. Since $\mathcal{U}$ is upwards closed, this set is in $\mathcal{U}$. By Łoś’s Theorem, $\prod_{i \in I} \mathcal{M}_i / \mathcal{U} \models \theta$. Since this holds for every $\theta \in \Sigma$, the ultraproduct is a model for $\Sigma$.
