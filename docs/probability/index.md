# 概率论

> 收录 **Weijun Xu** 主讲的 *Probability* 课程笔记。

## 课程主线

!!! abstract "课程主线"
    **概率空间 / 测度** $\longrightarrow$ **条件概率 / 独立性** $\longrightarrow$ **随机变量与联合分布** $\longrightarrow$ **变量变换 / 多元正态** $\longrightarrow$ **期望 / 方差 / $L^p$ 不等式**

## 笔记

1. [Foundations of Probability](lesson1.md) — 样本空间、σ-代数、条件概率、Borel–Cantelli 引理、随机变量、常见分布、期望与方差、Jensen 与 Hölder 不等式
2. [Random Vectors and $L^p$ Estimates](random-vectors-and-lp-estimates.md) — 联合分布与独立性、随机向量换元、指数与高斯例子、协方差矩阵、多元正态及矩估计
