# 测度论与实分析

!!! note "课程主线"
    从可数集与实数项级数出发，建立 Kurzweil–Henstock 积分。第二章通过
    Saks–Henstock 引理、Hake 定理与原函数，将积分推广到一般区间；
    第三章研究绝对可积性和单调收敛，再用示性函数的积分定义可积集的
    Lebesgue 测度，并证明总测度有限时的可数可加性。
