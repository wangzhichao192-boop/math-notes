# 测度论与实分析

!!! note "课程主线"
    从可数集与实数项级数出发，建立 Kurzweil–Henstock 积分。第二章通过
    Saks–Henstock 引理、Hake 定理与原函数，将积分推广到一般区间；
    第三章研究绝对可积性和单调收敛，再从示性函数的积分建立 Lebesgue
    测度：先处理可积集，继而通过局部可积性定义一般可测集，证明
    $\sigma$-代数结构、可数可加性与平移不变性，最后用选择公理构造
    不可测的 Vitali 集。
