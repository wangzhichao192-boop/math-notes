# 几何与拓扑

> 收录 **Xing Gu** 主讲的 *Geometry and Topology* 课程笔记（西湖大学）。

## 课程主线

!!! abstract "课程主线"
    **复数的平方根与缠绕数** $\longrightarrow$ **一般拓扑 / 连通 / 紧致** $\longrightarrow$ **同伦与基本群** $\longrightarrow$ **射影几何** $\longrightarrow$ **正则曲面的微分几何 / Gauss 曲率** $\longrightarrow$ **双曲几何**

## 目录

1. [Invitation](invitation.md) — 复数的平方根、缠绕数、亏角与 Gauss–Bonnet 公式
2. [General Topology](general-topology.md) — 连续映射、度量空间、拓扑空间、连通、紧致
3. [Homotopy and Fundamental Groups](homotopy-and-fundamental-groups.md) — 同伦、基本群、圆的基本群
4. [Projective Geometry](projective-geometry.md) — 射影直线与射影平面、交比、射影簇与圆锥曲线
5. [Differential Geometry](differential-geometry.md) — 正则曲面、第一/第二基本形式、Gauss 曲率、平行移动与测地线、Gauss–Bonnet 定理
6. [Hyperbolic Geometry](hyperbolic-geometry.md) — Riemann 球面、Möbius 变换、交比、上半平面模型
