## 常用记号

| 记号 | 含义 |
| ---- | ---- |
| $G$ | 群 |
| $H \leqslant G$ | $H$ 是 $G$ 的子群 |
| $H \trianglelefteq G$ | $H$ 是 $G$ 的正规子群 |
| $G / H$ | 商群 |
| $\operatorname{Hom}(G_1, G_2)$ | 同态集合 |
