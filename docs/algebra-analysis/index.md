# 代数与分析基础

> 收录 **Huayi Chen** 主讲的 *Fundamental Algebra and Analysis* 课程笔记。
> 上下两册合并于此，按章节顺序连贯阅读。覆盖教材正文中的定义、命题、构造、证明、例子和示意图；章末练习按约定省略。

## 课程主线

!!! abstract "课程主线"
    **基本逻辑 / 集合 / 映射** $\longrightarrow$ **群、环、模** $\longrightarrow$ **拓扑 / 极限 / 微积分** $\longrightarrow$ **范畴论 / 多重线性代数** $\longrightarrow$ **Haar 测度 / 算子约化** $\longrightarrow$ **微分几何 / Fourier 分析**
